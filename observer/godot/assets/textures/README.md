# Origin texture assets

These are the medium-detail material textures shipped with Origin 0.8.0-dev. They are original assets generated/processed for this project; no external download is required.

Active visible materials: terrain grass/earth, shore sand, cliff rock, bark, foliage, soil/resource earth, and water.

All visible base-color textures are 512x512 PNGs. Normal maps are retained for secondary meshes; the terrain itself uses geometric normals on the stable GLES2 path to avoid the lighting artifact seen in the previous build.
