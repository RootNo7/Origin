# Origin Project Details

- Current version: 0.7.2-dev
- Engine: Godot 3.6.x
- Runtime language: GDScript
- Runtime authority: `observer/godot/scripts/OriginRuntime.gd`
- First-person client: `observer/godot/scripts/Main.gd`
- Primary purpose: persistent systemic 3D virtual world and human test environment for future controlled LLM-agent experiments

## 0.7.2-dev

0.7.2-dev completes the practical single-application workflow. It also hardens save migration, inventory capacity, custom world-size resume, and scene-level smoke testing. Origin no longer requires a C++ executable or native compiler to run, render or test. The F1 console performs the normal developer/test operations inside the running Godot application.
