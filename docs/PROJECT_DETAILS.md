# Origin Project Details

Origin is a virtual-universe research project, not simply a game. VUniverse is the simulated reality; VEarth is its first world; Eris will be its first intelligent inhabitant.

Long-term: time, matter, physics, chemistry, environment, life, learning, multiple inhabitants, reproduction and evolution. These should emerge from explicit mechanisms rather than scripted story behavior.

Language strategy: C++20 for simulation authority; Godot 3/GDScript for lightweight observer/UI; Python later for AI/ML; YAML/text for metadata.

0.1.0 implements seeded terrain, fixed time, gravity/collision, materials, environment, basic water-phase boundary, entities, events, persistence snapshot, C++→Godot state bridge, Godot 3 observer and tests. It does not yet implement molecular chemistry, biology, Eris intelligence, reproduction, evolution, consciousness or realistic planetary simulation.
