# Run helpers

`run_origin.bat` launches the complete Origin application through Godot 3.6. No C++ compiler, CMake project, or native simulation process is required.

`run_tests.bat` invokes the same Godot runtime in headless test mode when a Godot executable is available.

The in-game F1 developer/test console is the primary one-place workflow for regenerating, saving/loading, testing, benchmarking, pausing, changing simulation speed and capturing screenshots.
